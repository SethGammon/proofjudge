## Findings

| ID | Severity | Area | Finding | Action |
|---|---|---|---|---|
| UX-1 | Polish | Verifier | Local fallback shows `Attestation status` as a red failure even when the receipt is otherwise verified. This is technically honest, but visually undercuts the success state for fallback demos. | Render non-blocking attestation absence as `WARN`, not `FAIL`. |
| UX-2 | Polish | Receipts | The receipt archive opens the full JSON drawer by default, making the view feel like a debug page before the user asks for JSON. | Collapse the JSON drawer by default. |
| UX-3 | Polish | Agent Identity | Architecture diagram uses scattered `to` labels and wraps visually out of order. | Make the flow read as one deliberate proof path. |
| UX-4 | Polish | Toasts | Success/failure toasts can linger while manually switching tabs, creating stale context in screenshots. | Clear transient toasts on manual tab changes. |
